# Remix
Browser-based DJ mixing, mashup and remix studio. Upload tracks, auto-detect BPM, match tempo, crossfade with bass swap, add EQ, echo, reverb and synthesized percussion, then export WAV. Optional Python server adds direct-link import and Demucs vocal splitting.
VIBE MIX STUDIO is a free, open-source web app for mixing existing songs. It has three modes: DJ mix, Mashup and Creative remix. It analyzes BPM and beat positions, matches tempos, aligns beats and applies equal-power crossfades with an optional bass swap. It also offers master EQ, echo, reverb, beat-synced pumping, a filter build-up and a synthesized darbuka-style groove, and it exports WAV. Everything runs locally in your browser through the Web Audio API.

An optional Python (FastAPI) server adds import from direct audio links and .m3u playlists, plus vocal and instrumental separation with Demucs. It does not download from streaming services. Use only audio you own or have the rights to use.
